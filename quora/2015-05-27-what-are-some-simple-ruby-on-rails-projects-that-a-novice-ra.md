# What are some simple Ruby on Rails projects that a novice rails developer can do?

I always find that I learn best by doing. Set yourself a project that you would personally find useful and then make it. 

For example, lets say to decide to make a blog in rails. Then blog about how you are learning rails on the blog you make. If the number of questions about this on quora are any indication then you will get a good amount of traffic. First it would be really basic, just enough to display your articles, but then you can start adding stuff.

For example, you might add a backend admin interface, then a login system, then a theme engine, then make it multi-user, then add facebook login... you get the idea, you can go like this for a long time.

The key is to think about what you want it to be like and then learn what it takes to get there. Many people seem intent on doing it backwards, in other words try to learn everything before you start trying. Then they get overwhelmed and quit. In other words just do it and if possible fail gloriously.
