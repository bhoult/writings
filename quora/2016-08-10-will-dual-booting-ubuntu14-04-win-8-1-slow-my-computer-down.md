# Will dual booting Ubuntu14.04/Win 8.1 slow my computer down?

Whoever told you that has no idea what they are talking about. Windows and Ubuntu are on completely different partitions. Windows is not even aware of Ubuntu since it does not understand the ext3 filesystem format. Ubuntu allows you to access the windows files, but only does so when you ask it to.

The only effect it will have is that you will have less storage space for each since you are splitting the drive between them. So long as you do not run out of space though this will not effect performance.
