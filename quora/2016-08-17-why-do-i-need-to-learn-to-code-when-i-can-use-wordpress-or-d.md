# Why do I need to learn to code when I can use WordPress or Drupal?

Customer: “This looks pretty good so far, but I saw this other site and I like how their menu bar shrinks and moves to the top when they scroll down. So if you can just change that then I think we are good.” … “Well, can't you just change the template, I mean you are a web developer right.” … “ Well, if my competitor can do that then he must be using something other than WordPress or drupal, why can't we just use whatever they are using?” …

See where this is going?

Sure you can make websites with a cms, you can add functionality with modules, you can buy pre-made themes. However, if what the customer wants does not fit in any of those things then you have to do some programming. Your choice comes down to learning how to do it or learning how to convince your customer that he does not want what he tells you he wants.

It is like insisting that all houses should be built with Legos so that you can avoid learning to use a hammer.
