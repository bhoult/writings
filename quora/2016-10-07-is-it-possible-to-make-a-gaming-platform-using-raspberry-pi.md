# Is it possible to make a gaming platform using Raspberry Pi?

Of course it is possible. It is just a matter of designing your game within the limitations of the hardware. This is no different than programming a game on any console except that the raspberry pi will be a lot more limited graphically.

Basically, if you target a specific platform then you have a hard limit on what that platform is capable of. If you target a PC or mobile device then you specify a minimum hardware requirement for which your game will run well.

For the raspberry pi you should design 3d with minimal polygons and small textures. For 2d you should be fine unless you have really compute intensive AI or large memory requirements.
