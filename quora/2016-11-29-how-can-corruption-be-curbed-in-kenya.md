# How can corruption be curbed in Kenya?

All actions/decisions have to be documented. Documents have to be public. Documents have to be independently validated. Questionable documents have to be explained publicly. Production of false documents has to be consistently punished.

Basically, apply something similar to the scientific method to politics.
