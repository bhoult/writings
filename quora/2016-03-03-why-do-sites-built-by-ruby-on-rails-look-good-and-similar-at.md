# Why do sites built by Ruby on Rails look good, and similar at the same time?

Rails just outputs HTML, CSS and JS just like anything else that goes into a web browser. So it is wide open as far as end appearance goes. However the people that tend to gravitate toward rails seem to have an artistic leaning, so the final appearance will probably be slightly more important to them than it is for people using other frameworks.

If appearance is important then they are likely to pay attention to the current fashion aesthetic trends. This probably leads to stylistic similarities that you are noticing. Also there are a number of frameworks that are becoming popular Bootstrap, Foundation, Gumby etc. These tend to encourage specific layouts such as grid layout where everything is put in blocks inside rows. And there are only so many variations on that. 

Also ruby tends to work well as a back-end service serving JSON to a front-end like Polymer, ember, angular, etc. These frontend frameworks have various defaults for widgets and ways that they adapt to different layouts. Newer Rails project are likely to use one of these which will lead to some similarity in appearance and behavior.
