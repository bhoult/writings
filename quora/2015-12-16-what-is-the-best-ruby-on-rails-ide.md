# What is the best Ruby on Rails IDE?

I have kind of settled on Codiad Web Based IDE by Fluidbyte 

It is really a pretty basic editor, but it is free, open source, and runs in a browser. I tend to do a lot of my editing on remote servers and this allows you to edit and do basic file operations on the remote machine directly so you don't have to ftp anything. Just hit ctrl-s and it is saved on the remote server.

I install it on my local machines as well, so basically I just do http://machine.com/codiad and I can login and edit anything I need.
