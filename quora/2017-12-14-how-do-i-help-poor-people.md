# How do I help poor people?

Mainly stop looking and start helping.

There seems to be a fear that you will help someone in some sub-optimal way. If this leads you to avoid helping at all then this is what you need to learn to stop doing.

See a need, and so far as you are able and willing, do something about it. Do it now, with what you have. Help badly, get messy, learn how to help better and repeat.
