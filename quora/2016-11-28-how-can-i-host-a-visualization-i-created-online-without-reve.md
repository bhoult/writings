# How can I host a visualization I created online without revealing the code?

There is nothing that you can do that will prevent them from using the “view source” on their browser. If the browser can read the files to display them then those files have to exist where a person can download them. The whole idea behind making HTML and CSS human readable instead of a compiled binary format is so that people could see the source.

You could save the finished screen as an image and let them download that.

You could use an obfuscator like Javascript Obfuscator or JavaScript HTML Code/Text Obfuscator but if someone really wanted to they could work around it.
