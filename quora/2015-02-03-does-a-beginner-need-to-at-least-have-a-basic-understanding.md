# Does a beginner need to at least have a basic understanding of HTML and CSS to learn a language like PHP, Python or Ruby? And which of the latter 3 is better?

Only if you want to use them to create websites.

Python and Ruby are fairly equivalent, but Ruby tends to get most use with Rails (web). So if you are not doing web programming then python would probably be your best bet.

If you are doing web programming then I think Ruby on Rails is slightly better than python. In any case you would also need to learn html, css, and javascript (to some extent)

PHP has the biggest user base, but is also mainly applicable to websites. It is also arguably the least well designed and does not really encourage good programming practices. However if you just want to do something simple then it should suffice.

The "new-hotness" is probably node.js which is just server side javascript. If you want to just learn one single language that you can use for everything then maybe consider javascript. It is not necessarily the "best" at everything, but that may be less important than having to learn two languages.
