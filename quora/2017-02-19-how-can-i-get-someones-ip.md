# How can I get someone's IP?

Get a server, host a picture or file on it, email them a link. If they download the file or view the picture their IP will show up in the log on your server.

Keep in mind though that their IP can change. Most home isp's assign a different IP each time you reconnect. So the IP you obtain will only be valid for a short time.

Also the IP will probably belong to their router / modem, not their actual computer unless they have port forwarded some or all ports.
