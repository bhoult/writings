# When should I develop a web application on PHP vs. Django vs. Ruby on Rails?

When you are an experienced PHP developer and don't know about or have time to learn anything else. Or when the project is relatively simple and will not need to be extended and maintained in the future.

There are those that have strong opinions that PHP is a reasonable language and although it has improved in recent years I would still avoid it whenever possible. This is just an opinion, but I suspect that unless you are a very self-disciplined developer with a lot of knowledge about best practices then the further you go with PHP the less maintainable it will become. Django and Rails tend to steer you toward best practices and encourage testing and maintainability in the long run.
