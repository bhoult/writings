# What is the cheapest, expandable Ruby on Rails hosting?

For all round flexibility I would use Amazons cloud services. It is not the least expensive, but a small server 1gb mem 8gb hdd, 1 core only costs me about $10/mo. Initially it was one of the most expensive options but prices keep going down. Now they have an even cheaper option with 512k for about $6/mo.

The advantage is that you can scale at any time to any size you need on both processing/memory and drive space and you only pay for what you use. Most other virtual server hosts sell everything as a unit so if you need a lot of storage but not much cpu you have to scale everything up to accommodate. With amazon you can have a tiny cpu with many terabytes of storage, or a 24 core server with just a few gb of storage.

Plus they offer a year for free.

The downside is that there is a little bit of a learning curve, but as far as I can tell the flexibility, reliability and services provided are unparalleled. As many have mentioned, cheap servers can lead to unforeseen expenses and downtime. With amazon you can scale from cheap to powerful easily.
