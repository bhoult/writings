# I want to be an app developer/web designer/web developer. How do I get a better understanding and a job?

All of the other answers on here are good. I would suggest this order: html, css, javascript, linux, database (sql), (ruby or python) with a popular framework for whichever you choose.

It seems like this is a question that is asked in slightly different form every couple days on Quora though. So maybe look through some of those answers as well.

What most don't cover is why you suddenly want to learn these things. There is something to be said for getting a job, and programming seems like a good way to make decent money relatively easily. When you start to begin studying it the question will be weather you really like it and can't wait to learn more or weather you just wish you could get done with it so you can go do something else.

It seems like many new programmers really don't like programming that much, but they do it because they want to make money. The problem with this is that they do it really badly. They do it badly because they only learn the minimum to get by. Even programmers that love programming can get tired of it after a number of years. 

If you find yourself in this situation then think about what you wish you were doing instead of programming and consider if you can make enough money at that. It may even be possible to use what you have learned programming and apply it to something you are truly passionate about. 

You could also specialize. For example if you just learn HTML and CSS really well then you could probably become a front-end developer. Or if you just learn databases you could be a DB Admin, or a Linux admin.

Hopefully you find you love programming and then you will spend the rest of your life learning new things.
