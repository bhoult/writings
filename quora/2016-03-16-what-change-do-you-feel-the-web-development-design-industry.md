# What change do you feel the web development/design industry will have in the next 5 years?

I expect you will be safe for the foreseeable future. The main reason is that a web-presence is almost a requirement for any business these days. They used to use yellow pages, billboards, signs, newspaper, radio, tv and they still do to some extent. However when someone is looking for something these days the first stop is their cell phone and the second is the website.

In addition to the growing demand for a web presence, the web itself is evolving. A few years ago tablets and phones were a niche and websites were predominately fixed width. Now mobile devices have surpassed full computers in how people view the web and all the existing sites had to be rewritten. This is a huge job, and will be ongoing for some time. 

But new technologies are still coming that will put older sites at a competitive disadvantage. HTML5 + Javascript replacing flash, web assembly, web components, css animation, virtual reality. This onward march will not end any time soon, and so long as innovators are innovating there will be a need for existing websites to evolve and that will take programmers... lots of them.

In addition to a web-presence, automation is becoming key to efficiency and therefore the ability to compete. The web is more and more becoming the front end to large backend applications that store and organize data in ways unique to each business. 

Security will also become more of an issue. Legacy apps will need to be rewritten or carefully analyzed to prevent intrusion. People will need to be experts on current techniques used by intruders and will have to be proactive to prevent them from succeeding. This will become a huge industry in itself. 

It is good that you enjoy the learning process. As long as that remains true you will be riding the leading edge. Those that resist change will find static niches and settle there until they retire.
