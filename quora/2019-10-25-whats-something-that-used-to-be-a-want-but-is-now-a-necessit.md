# What’s something that used to be a want, but is now a necessity for survival?

If you mean actual survival… as in not dying. Then the requirements are food, water, air, shelter. Same as they have always been. Everything beyond those are a want.

If you mean what is necessary to live in a modern society like an average person, well, that is a different question.
