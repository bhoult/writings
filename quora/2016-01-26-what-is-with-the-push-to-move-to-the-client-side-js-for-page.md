# What is with the push to move to the client-side JS for page rendering? What possible gain is there to be had for pushing everything off the server and onto much less powerful devices?

Basically the less powerful client side device only has to do work for one user. The server side may have to handle hundreds of users per second. Also by transmitting just json data instead of the finished html the bandwidth required can be greatly reduced and the site will be faster as a result.
