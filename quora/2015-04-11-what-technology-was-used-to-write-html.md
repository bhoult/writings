# What technology was used to write HTML?

Well... perhaps XML (Extensible Markup Language), since HTML is just specific subset of XML. I don't think it would really be considered a technology though since it is just a way of saying something. It is more like a language. If you write something in HTML then a program that can read HTML will hopefully be able to get what it needs from whatever you wrote.
