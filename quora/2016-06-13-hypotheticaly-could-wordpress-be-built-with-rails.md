# Hypotheticaly, could Wordpress be built with rails?

I agree that you could learn rails on your own and save a lot of money. You will still need to learn html, css, javascript, sql, and some linux. The difference is you will have to be self motivated as nobody will be assigning you anything.

Hypothetically WordPress could be written in rails, but the power of WordPress or any of the established cms systems is in their community and plugins. Those would not be possible to replicate any time soon. So the choice people would have is to use your WordPress like cms, that has a small community and plugin ecosystem and has just started, or use actual WordPress which has been polished and debugged for many years. Few would use your system without compelling reasons.

But basically rails with gems is half way between a cms and a custom application. It is more flexible than WordPress but takes more expertise to use. I use both, for a basic website with no special needs, it is easier to use a cms...anything beyond that then use rails. This prevents you having to learn php, while still taking advantage of its legacy of mature software.
