# Can I find a job as a Ruby engineer without coding Ruby on Rails or any web framework?

You could probably work as a server admin. Ruby makes a really good scripting language so you could automate all kinds of repetitive stuff or make scheduled jobs for backing stuff up or tasks like that.

Rails and all the other Ruby frameworks were written in Ruby, so your question seems kind of like "Can I be a ruby engineer and never have to write anything complicated?"... either that or you have a bad case of "not invented here" syndrome, and want to make your own version of stuff. 

The thing about the frameworks is that it makes it much easier to work with others and collaborate. If you find you need to add a second programmer to a rails project then you just need to hire someone that knows rails and they will be up and being productive in a few days. If you did it all yourself then you would need to train them in the way you do it, which probably is not consistent so they have to carefully go over all the code before they can add anything.

A framework is like having half the job done before you even start. It is like having a huge team of developers for that half the project doing all your work for you. Why would you not want that?
