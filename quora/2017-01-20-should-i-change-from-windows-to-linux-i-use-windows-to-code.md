# Should I change from Windows to Linux? I use Windows to code in Python, and for Youtube videos, Facebook, school work, and do translating jobs. I usually game, but want to be more productive. I use Win7 ATM. Linux seems clean, productive and fast.

I dumped windows for similar reasons about a year ago. Up until that time I kept it mainly for gaming, netflix and because I had to use outlook for work.

Outlook is now available as a web app, netflix and amazon video work fine on chrome, and there are lots of games on steam. Some / Most AAA titles are still missing, but like you I want to spend less time playing video games… so that can be a plus.

You may have some transition pain if you are not experienced on the command line though. While you may be able to get away without it these days, you would do well to learn the basics since most online help will reference the command line in some way.

Other than that, (my opinion) is that you are correct, it is lighter, faster, cleaner, simpler and less prone to trouble than windows ever was. I also run windows in a VM for the rare occasions when I have to use some specific windows software… but that only happens once every few months or so.
