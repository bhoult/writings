# What is the fastest way into getting started with web development? HTML, CSS, and JS or WordPress and PHP or RoR?

If you are in a hurry, WordPress first. Using prebuilt templates and modules, you can just add content and probably have something up in a day. You might want to change how some stuff looks but can't figure out how. Then you will need to learn HTML (easy) and some css (will take some practice). Up to this point you don't have to learn any “programming”.

Eventually you will want to change stuff that can't be done with just HTML and CSS, or you may want to add some minor interactivity. This is where JavaScript comes in. You can do quite a bit with just the basics and maybe some jQuery.

At this point you have a choice to make. The next step enables you too accomplish literally anything, but will determine how you do so. You can learn php which is what WordPress is written in. This will allow you to write your own WordPress modules or even modify the WordPress software. You will still need HTML, CSS, and basic JavaScript.

Or you can just learn more JavaScript and use node which allows you to use JavaScript on the server the same way that you do on the browser. At the moment JavaScript is the only language that runs on the browser so if you only want to learn a single programming language then this is the only choice.

Or you can learn Ruby / rails. Ruby is a language that is very easy to learn, read and debug. I have used 14+ languages and Ruby is by far my favorite to program in. But it has limitations, mainly that while it is fast to program in, it runs slow. Sometimes this can become an issue. Also rails is a collection of best practices, and really you have to learn them all to be proficient. It is kind of half way between a cms like WordPress and writing your program from scratch. It has a bunch of mature and well written “gems” which are kind of like modules so you don't have to reinvent the wheel each time, but you design your application and build it how you want instead of trying to take a cms and figuring out how to make it do what you want instead of what it was made to do.

Btw, there is a JavaScript (node) clone of rails called sails if you go the JavaScript route but want something like rails.

Personally I believe the future is in lightweight REST api's on the server and almost everything else on the browser (JavaScript). Look into “server less" programming. So I would recommend going the JavaScript route for this reason and for the universality and huge ecosystem it has. When webassembly comes to pass there may be other languages on the browser, but JavaScript will always be there.

You may also want to learn Linux or osx and command line basics. You can use windows but it will be a lot more difficult to follow along with online tutorials. The new windows Linux subsystem may make this easier.

Setup a hosted WordPress account to play around with (WordPress.com: Create a website or blog free). They each have different strengths and weaknesses. Regardless of wether or not you end up using them, you will learn from them and it will make you a better programmer. If you are not enjoying it then you will never reach this step.
