# *** Nerd Alert ***

*** Nerd Alert ***
Nerdy content follows, you have been warned.
-------------------------------------------------------------
So you may have noticed that I have been babbling on about AI coding tools for the past week or so.  Over the weekend I decided to write a POC for an idea that I had a long time ago.  I find myself doing a lot more of this now that it takes so much less effort.

I decided to release this one as open source, so here you go:
https://github.com/bhoult/mutation

It is basically an artificial life simulation where "agents" consist of small bits or code and are mutated over time in order to gradually evolve.   The interesting part is that I did the whole thing in my spare time over the July 4th weekend, using Claude Code.

I deliberately did not write a single line of code for this.  Just kept telling Claude what to do for like 20 hours.  But it's not like regular programming, you don't have to maintain constant concentration.  In fact you usually get a few minutes break between each prompt, while it does what you told it to.   I was literally working on two other projects at the same time.

Anyway if you want to contribute, feel free.  If you just want to see what is possible these days just have a look at the documentation at the above link.

[link](https://github.com/bhoult/mutation)
