# Writings Archive

Written by [Brandon Hoult](https://hoult.co).

Everything in one place, no external dependencies. One Markdown file per piece,
grouped by source, named `YYYY-MM-DD-title-slug`. Images and videos live alongside
as local files referenced by relative path.

- **quora/** — 278 answers (2014–2026)
- **facebook/** — 1135 posts (2008–2026): written pieces plus every post with photos or video.
  Text-only status updates, birthday wishes, link shares and meetup requests removed.
  Frontmatter `context` marks timeline vs. posts on other pages/profiles.
- **minimal-intentions/** — 40 blog posts (2010–2014)
- **images/** — all photos and videos, deduplicated by content hash

Each file carries YAML frontmatter: title, date, source, context, url (where available),
location (check-ins), tags. Total: 1453 pieces.
